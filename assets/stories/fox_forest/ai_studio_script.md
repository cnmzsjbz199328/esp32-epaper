# 《小狐狸的月光森林》AI Studio 台词脚本

## 全局声音指导词

请用温柔、清晰、自然的中文普通话讲述儿童睡前绘本。声音亲切、有画面感，语速略慢，句间停顿自然；遇到“月光、星星、秘密、朋友”等词时带一点温柔的惊喜。不要夸张表演，不要朗读标题、编号、说明文字，也不要添加背景音乐或音效。

推荐声音：`Achernar`（Soft · Higher pitch）。

## 生成规则

每次只把下面一个场景的“台词正文”粘贴到 Speech block 中，单独点击 Run 并下载。下载后按编号命名为：

```text
000.wav  场景 1
001.wav  场景 2
002.wav  场景 3
003.wav  场景 4
004.wav  场景 5
```

不要把场景标题或文件名粘贴进 Speech block，避免它们被读出来。

## 场景 1：森林入口 → `000.wav`

夜色刚刚降临，小狐狸围着蓝色围巾，走到了月光森林的入口。前方的小路弯弯曲曲，好像在邀请它开始一场温柔的冒险。

## 场景 2：发光的石头 → `001.wav`

走了没多远，小狐狸在树根旁发现了一块会发光的石头。它伸出小爪子，轻轻碰了碰，石头立刻像星星一样闪了一下。

## 场景 3：猫头鹰的声音 → `002.wav`

这时，树枝上传来一个温柔的声音。原来是一只猫头鹰，它告诉小狐狸，沿着月光照亮的小路，就能找到森林里的秘密。

## 场景 4：穿过小溪 → `003.wav`

小狐狸跟着猫头鹰来到一条小溪边。它踩着一块又一块平坦的石头，小心地走过溪水，水面上的月光也跟着摇晃起来。

## 场景 5：平安回家 → `004.wav`

天快亮了，小狐狸和猫头鹰一起走回森林入口。它知道，真正的宝藏不是发光的石头，而是在黑夜里遇见了一位朋友。
