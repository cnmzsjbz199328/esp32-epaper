# 故事库扩展场景映射

本表是从现有六场景资产扩展到全年龄/偏成人向完整情节版本的工作底稿。`reuse`
表示复用现有 `source/scenes/` 关键帧；`add` 表示需要补充新图。扩展后的编号是
最终 `story.json`、图片、FVID 和音频必须共同使用的编号，旧音频不能沿用。

## 执行约束

1. 先冻结本表对应的完整中文脚本，再生成或下载新的 TTS；每个故事使用独立人声。
2. `reuse` 只表示复用画面构图，不表示沿用旧编号语义；扩展后必须重建连续编号的
   FVID、`story.json` 和音频映射。
3. 每个故事当前预计补 8 张图；如果新脚本合并相邻情节点，必须同步减少图片、音频
   和场景编号，不能只修改文字。
4. 现有《奥德赛》六段音频只对应旧脚本，暂不导入扩展包；Midsummer 和 Tempest
   尚未生成的音频也等脚本冻结后再制作。
